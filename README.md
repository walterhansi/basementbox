# Basement Box

Workout-Begleiter für das Training im Keller oder im Garten (private Nutzung).

- **Am PC:** Übungen aus Obsidian holen (Häkchen „Übungsauswahl“, Erkennung über die ID), eigene MP3s laden, Workouts zusammenstellen, senden.
- **Am Handy / Chromebook:** holen und das Workout in Echtzeit abspielen – mit Bild, Übungsname, Uhr, Musik, Signaltönen und Sprachansage. Läuft auch ohne Internet.
- Es wird nichts protokolliert; dafür ist fitlog da.

Die Daten (Workouts, Übungsbilder, MP3s) liegen nicht hier, sondern in einem privaten Repository im Ordner `basementbox/`.

`tresor.html`: einmalige Umstellung des Obsidian-Tresors (Häkchen `fitlog_auswahl` → `Übungsauswahl`, ID `UE-1656` → `1656`).
